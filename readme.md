# Evolution-web

## Admin seed editor

A standalone administrative seed editor with drag-and-drop card assignment is available under `tools/admin-seed-editor`.
Start it locally with:

```
npm run admin-editor
```

The tool exposes a web UI on `http://localhost:4000` that lets you tweak room settings, build decks, and export the YAML seed that can be pasted into the in-room `/admin` command dialog.
